# 技能演出、专属招式与触感反馈

内容版本 ch10.3。全部 111 招都有画面或动作特效，其中 51 招为稀有／神兽专属。

每次实际出手独立播放，速度带来的第二、三次出手也各播一次。近身招式前冲／挥击，远程招式蓄力／飞行／命中，18属性使用不同符号、颜色与粒子；治疗、护盾、凝神、削弱和天气各有表现。专属招式附加光阵和名称演出。落空／免疫不播放受击震动，睡眠或PP不足取消的行动没有虚假攻击。演出期间锁住继续按钮与新指令，结束后继续经典文字流程。开启系统减少动态效果后改为短暂淡入淡出。

战斗按日志位置保存有限的演出记录和双方画面状态，HP与换人按消息显示。读档只恢复结算状态，不自动重播旧动画，也不重复消耗PP、抽取随机数或发放奖励。

## 触感反馈

标题、菜单、背包、技能、队伍、地图选择、对话、确认按钮和半透明方向键统一接入。确认按钮轻触，命中提供一次冲击反馈，要害提供更明显反馈；取消的行动与禁用按钮无反馈。连续按键限频80ms，长按移动不逐格震动。设置中可统一关闭，偏好保存在设备本地，分享存档不会改动接收手机的偏好。iOS使用系统触感API，Android使用系统触觉效果，网页仅在浏览器支持振动时响应；不支持或调用失败不影响游戏。原生接口需要包含expo-haptics的新客户端，网页截图不代表真机马达验收。
