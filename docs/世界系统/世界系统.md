# 探索、战斗环境与剧情技能（ch3.1）

这些规则已接入现有三道馆、十三张地图，不要求重开存档。机器可读配置见 [world-rules.json](世界规则.json)，由 `pnpm exec tsx tools/export-world-rules.ts` 从运行代码导出。

## 击败奖励与成长节奏

每只对手倒下时立刻给经验和金币，不必等整队对手打完。设对手等级为 L，强度系数 S = clamp(种族总值 / 350, 0.8, 1.5)：

| 对手       | 经验池                  | 击败金币          |
| ---------- | ----------------------- | ----------------- |
| 野生       | floor(L × 32 × S)       | floor(L × 8 × S)  |
| NPC 训练师 | floor(L × 32 × S × 1.5) | floor(L × 18 × S) |
| 道馆馆主   | floor(L × 32 × S × 2.5) | floor(L × 32 × S) |

参加过本场战斗的伙伴均分经验池，健康后备各得经验池的 25%。参与者即使因同轮反伤倒下也保留已取得经验，升级不会复活。序章救博士固定给 16 经验、8 金币，避免借用伙伴过早进化。

NPC 获胜仍给原有旅费；重复练习允许正常获奖。新徽章再给 `300 × 当前徽章数量` 金币、`敌方等级和 × 16 × 当前徽章数量` 经验池、成长果两颗、高级星纹球两个。奖励按徽章总数递增，不按某座道馆必须排第几。每个馆主的新徽章奖励仅一次。练习对手随出战伙伴等级适配，最低两级，允许培养刚捕捉的低等级伙伴。

捕获给原有队伍 `对手等级 × 16` 研究经验，不给击败金币，也不给刚捕捉的精灵反过来奖励自己的经验；逃跑不发奖。战败保留此前已经结算的经验和金币，再按原有规则支付 5% 旅费并回精灵中心。战斗保存每个已结算对手的 ID，下一只、结算页、强制换人、存读和传档都不会重复发放。旧版进行中的对战不追补已经通过的对手。

保留快、中快、中慢、慢四条三次经验曲线；等级越高，下一级所需经验越多。Lv.100 封顶；每级 1–10 能力点、手动／自动加点和既有进化规则继续使用。

## 剧情通用技能和精灵中心

| 技能   | 剧情解锁               | 使用                                                                    |
| ------ | ---------------------- | ----------------------------------------------------------------------- |
| 剪藤术 | 森林救援后向穗禾交报告 | 草系物理，50 威力；作为可学习战斗招式，原剪藤工具仍可由草系馆获得       |
| 碎岩术 | 归还旧矿山工牌         | 格斗物理，55 威力；原碎岩工具仍可由岩石馆独立获得                       |
| 冲浪术 | 完成旧灯塔维修支线     | 水系特殊，80 威力；队伍任意伙伴掌握后可在普通水面移动，无属性或等级限制 |

这三招不进入升级学招表、野生自带招式或商品。剧情旗标是永久解锁凭据；复刻剂也不能绕过剧情。已解锁后在晨芽镇、苔丘镇、石脊城、潮汐港任意精灵中心免费学习、遗忘和重新学习，进化后保留通用技能册。

走到治疗员身旁，打开菜单「精灵中心」，即可恢复全队 HP、PP、异常状态，或选择队伍／仓库伙伴管理技能。与治疗员交谈也会立即免费治疗并设置战败返回点。至少保留一个已掌握技能；满四招要明确选替换位。普通自然学招和已复刻招仍可在城镇的伙伴页免费回忆；剧情通用招只在中心办理。

潮汐馆原有渡水装备继续有效，可不带冲浪伙伴渡水；冲浪支线也不要求先打潮汐馆。可在任意普通水面游行并触发对应水域遭遇。水上禁止替换、入库最后一个会冲浪的伙伴，避免失去返岸能力；有渡水装备则不受这项保护限制。渡水不消耗战斗 PP，异常与昏厥不抹去野外技能知识。

## 野外天气与生态

新档先晴朗四分钟，之后户外每三至六分钟变换一次天气。天气有独立随机种子，地区影响下一种天气的权重：沿海更易降雨和雷雨，山地更易飘雪和扬沙。室内、菜单、对话、成长选择、战斗与后台暂停自然天气计时；存档和双机传档保留天气与剩余秒数，不按现实日期重抽。

| 天气 | 更活跃的属性     | 受抑制的属性 | 野外步速                              |
| ---- | ---------------- | ------------ | ------------------------------------- |
| 晴朗 | 无               | 无           | 原速                                  |
| 烈日 | 火、草           | 水           | 草地／高草 ×0.95                      |
| 降雨 | 水、电、虫       | 火           | 土路 ×0.9，草地／高草 ×0.85；桥梁不变 |
| 雷雨 | 电、水           | 火           | 露天陆地 ×0.8，桥梁 ×0.9              |
| 薄雾 | 幽灵、超能力、恶 | 无           | 露天陆地 ×0.9                         |
| 飘雪 | 冰               | 火           | 露天陆地 ×0.8，桥梁 ×0.9              |
| 扬沙 | 岩石、地面、钢   | 水、草、虫   | 露天陆地 ×0.85                        |

偏好种类在**原栖地**的相对权重乘 1.8；受抑制的乘 0.6，其余乘 1；多属性只判一次，偏好优先。它们会改变出现概率，绝不把其他生境或剧情限定精灵塞进随机池。已生成的探索发现点保持原结果，不能用天气刷新已领取补给。所有普通种仍有非零相遇概率，不必等某种天气才能通关。

## 战斗天气

入场复制当前天气，战斗期间不随户外秒数变化；矿山和室内道馆自然天气为晴朗。Lv.32 学招表加入按精灵属性配置的祈晴、唤雨、扬沙幕、唤雪、凝雾；也可回忆和复刻。技能天气持续五轮，包含施放轮，替换前一个技能天气，结束后恢复入场天气。

| 天气 | 伤害与能力                                        | 招式交互                                                     |
| ---- | ------------------------------------------------- | ------------------------------------------------------------ |
| 晴朗 | 无修正                                            | 无修正                                                       |
| 烈日 | 火伤 ×1.5、水伤 ×0.5；草系有效速度 ×1.15          | 回复术恢复最大 HP 的 2/3                                     |
| 降雨 | 水伤 ×1.5、火伤 ×0.5；水系速度 ×1.15              | 电系招式命中 ×1.1；回复术恢复 1/4 HP                         |
| 雷雨 | 水伤 ×1.3、火伤 ×0.7                              | 电招命中 ×1.2、飞行招命中 ×0.85；回复术恢复 1/4 HP           |
| 薄雾 | 幽灵与恶系伤害 ×1.2                               | 对敌招命中 ×0.85，幽灵／超能力招与自身强化例外               |
| 飘雪 | 冰伤 ×1.25、火伤 ×1.15；冰系物防 ×1.5、速度 ×1.15 | 回复术恢复 1/4 HP，无冰雹扣血                                |
| 扬沙 | 地面伤 ×1.15，岩石系特防 ×1.5                     | 轮末扣最大 HP 的 1/16，岩石／地面／钢免疫；回复术恢复 1/4 HP |

天气乘区在伤害取整之前结算，要害仍将普通伤害精确翻倍，属性免疫保持零伤害；不修改十八属性克制表。命中概率最终限制在 100%，自身强化和天气招式不会因雾天落空。速度变化从下轮锁定额度时生效，沙暴／异常轮末伤害一轮各一次，不随高速连击重复。

## 地形与移动

| 地形                       | 基础速度 |
| -------------------------- | -------- |
| 土路、桥梁、栈道、室内地板 | 100%     |
| 矮草地                     | 92%      |
| 高草、花丛                 | 78%      |
| 山城碎石、矿道             | 82%      |
| 沿海沙滩                   | 75%      |
| 水面、浮标水路             | 70%      |

地形速度与天气倍率相乘，下限 50%；水面不叠加陆地天气惩罚。每格输入间隔 `round(160 / 速度)` 毫秒，移动动画 `round(140 / 速度)` 毫秒，步态覆盖同一时长。长按、键盘和快速点按共用限速。减速影响手感，不占战斗回合，不改变地图尺寸和必要道路通行。

## 稀有度、捕捉与大师球

遭遇权重同时参考本地基础权重、种族总值、进化阶段、物种原始捕获率和天气。强种、进化形态、原始捕获率低的种类更少出现；计算公式见导出配置。剧情稀有／神兽仍只通过对应事件开启，天气不能提前刷新。

普通星纹球捕捉倍率 ×1（100 金币），超级星纹球 ×1.5（250），高级星纹球 ×2.5（600），所有已开放城市商店都有。捕捉还受等级与种族强度影响，降低 HP、睡眠和其他异常有帮助。常规球最终概率在 3%–95% 之间；战斗背包显示当前精确捕获概率。

大师球对**已经开启相遇的野生和剧情精灵**为 100%，包括未来神兽；不能捕捉 NPC 持有的伙伴或序章救博士的受保护对象，也不代替剧情调查。全篇只预留三处、每处一次：

1. 潮闸调查结案：当前可取得一个；旧档已结案的可回访沐舟补领一次。
2. 联盟生态研究结案：未来章节预留一个，当前不可领取。
3. 远古守护者约定：未来章节预留一个，当前不可领取。

商店、印记兑换、野外掉落、随机发现、重复练习和道馆奖励均不产出大师球。存档保存已领奖来源与已用个数，校验 `领取数 = 持有数 + 使用数`，拒绝重复来源、未开放来源或超额库存。普通存读、导入与双机传档保留账本；像其他纯离线进度一样，手动恢复自己较早的整份存档会回到当时的状态，不提供联网账号防回滚机制。

## 自由推进边界

入门故事和各馆必修练习之后，三座已开放道馆的六种顺序都可以通关。普通城际道路、维修桥、道馆入口不要求特殊天气、冲浪、其他道馆徽章或稀有精灵；渡水增加捷径和探索面。剪藤／碎岩工具沿用既有独立来源，技能故事不追加道馆门槛。森林—矿山—港口调查依证据接续，港口家书、灯塔与栖地支线仍可自由安排。后续五馆与两处大师球来源尚未实现，不显示为已可通关。
