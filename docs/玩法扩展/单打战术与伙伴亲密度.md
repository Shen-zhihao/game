# 单打战术与伙伴亲密度

内容版本 ch11.4，继续支持 ch11.3 及此前受支持的存档。不改变速度带来的每轮 1～3 次行动规则。

## 守住、寄生与吸取

- 新增「守住」，原「坚壳」仍是提升防御的独立招式。守住有较高先制度，只能在己方本轮第一次行动使用，成功或失败均消耗本轮全部剩余行动，不允许高速伙伴先攻击再守住。成功后阻挡本轮对手招式，不阻挡中毒、灼伤、天气或寄生等持续伤害。连续轮使用成功率递减；换下场清除相关场上状态。
- 新增「寄生种子」。草属性免疫，同一目标不能重复播种。每轮末扣除目标最大体力的八分之一（不足时只扣剩余体力），按实际扣除量治疗施术方当前存活的在场伙伴。被寄生者换下场或倒下后解除；施术者换人不会解除对方寄生。
- 新增「吸取」「超级吸取」「终极吸取」「吸血」「吸收拳」「吸取之吻」「汲魂」。按本次实际造成伤害的一半恢复自身体力，不按过量伤害或自身最大体力计算；未命中、属性免疫或被守住时不会凭空回复。既有专属技能的固定回复效果仍保留。
- 新招式加入等级学招与现有回忆体系。馆主、联盟及冠军再战队伍按原有属性、等级合法配招，依据持续伤害、回复收益、连续守住成功率等选择战术，不新增额外行动。
- 战斗内保存保留寄生、守住及连续使用记录；换人、倒下、战斗结束会进行对应清理，战报与详情显示实际效果。

## 同行与互动

- 亲密度范围为 0～255，新伙伴与缺少该字段的旧伙伴从 40 开始。读取或查看旧档不会凭空补发历史步数收益。
- 未昏厥的队伍伙伴每有效同行 128 步增加 2 点；仓库伙伴、原地转向、撞墙、快速旅行和单纯经过时间不计步。
- 伙伴详情增加「陪伴互动」，一次增加 8 点。再次互动需要该伙伴再同行 64 步且实际游玩 60 秒，两项均满足才可继续。休息推进日历或重新读档不能重置冷却。
- 界面显示当前亲密度、同行进度、不能互动的原因及剩余要求。战斗、对话、活动、成长选择等过程不能互动，昏厥伙伴须先恢复。

## 特殊进化路线

以下均为额外可选路线，需要伙伴随队同行，不删除或提高原有等级／道具进化要求。伙伴详情、图鉴、栖地与培养建议显示条件；满足特殊路线时不消耗原进化道具。

- 叶耳兔：Lv.16、亲密度 120、白天，可以提前进化；原 Lv.22 路线保留。
- 黄昏狐：Lv.28、亲密度 160、夜晚，可免道具进化。
- 草铃雀：Lv.28、亲密度 160、白天，可免道具进化。
- 棱晶螺：Lv.32、身处石脊旧矿山或回声深矿、当前掌握「晶岩坠」，可以提前进化；原 Lv.38 路线保留。
- 温泉猿：Lv.32、身处温泉冷石谷、当前掌握「潮汐弹」，可免道具进化。

白天为 06:00～18:00，夜晚为 18:00～次日 06:00。招式条件要求当前四个技能中掌握，不以曾经学过代替。进化确认时重新检查条件，保留亲密度、经验、能力培养与历史记录。若在战斗、对话或训练师接近过程中达标，提示会暂存，等安全结束且条件仍满足后出现；延期提示也会随存档保留，主动暂缓后不会立即重复打扰。

## 验证边界

按仓库约定，回归脚本和隔离验证存档位于仓库外，不新增测试框架或测试目录。本批仅进行类型、lint、规则／存档回归与云电脑浏览器开发预览验证，不打包、不执行原生构建、不部署。具体执行结果以交付说明为准。

本批没有新增繁殖、条件球、双打、畏缩、场地钉子或地图级机关。
