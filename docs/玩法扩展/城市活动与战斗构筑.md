# 城市活动、道馆机关与战斗构筑

适用内容版本：ch11.0。此文说明本批代码实现，不代表应用已打包或真机验收。

## 城市活动

捕捉入门后即可参与，不要求徽章或地区调查。除潮汐港外，进入本城扩建街区的工坊，调查屋内东南侧工作台；潮汐港在潮声滨园北岸找垂钓员白汀。地区地图显示活动名称与位置，任务管理包含对应委托。

每项活动首次完成可领取对应道具一件及旅费180；对应委托另外奖励旅费120和调查印记2枚。首次奖励单独记账，背包或旅费已满时保留奖励，重玩只刷新成绩。钓鱼完成后需选择进入遭遇，并在普通野生战斗中投球，才会获得精灵；钓点从原有海岸水域生态池取样，不加入剧情限定精灵。

活动操作自动存档。离开工作台会保留未完成棋盘，再次调查可继续；重置本局才重新开始。小游戏不依赖抢点或现实时间，可通过触摸按钮完成。推石机关另外支持网页方向键。失败可以免费重试。

地图上的活动入口使用对应实物插画：育苗盆、藤槽、水电检修台、矿石凿台、风铃架、锻炉、镜架、天平和拼图板。面包房显示烤盘，图书室显示记录本。野外线索按实际内容显示枝条、足迹、图板、观测镜或仪表，删除原先被室内外调查点共用的悬浮叶片与星标图案。

## 道馆机关

八馆各两处机关，共16处：草馆引露槽、岩馆推石配重、水馆浮桥水路、电馆检修回路、风馆铃片排序、火馆温控锻打、镜心馆镜面反射、星岚馆砝码平衡。

解开棋盘后设置原机关标记，原有地图通道随即打开。第二处仍需先完成本馆学徒对战，不增加其他道馆、天气或稀有精灵的门槛。老存档已经启动的机关继续生效，无需重做；训练师仍遵守获胜后不再触发、战败可重试。

## 特性与携带道具

全部250种形态按当前主属性配置固定特性，共16种，包括低体力属性增幅、蓄电、地面免疫、物理或特殊减伤、异常免疫、沙天加速、主动换下回复和满体力保命。进化后读取新形态的特性，旧存档自动获得对应效果，培养点与自然成长记录保留。本批没有随机特性或隐藏特性。

11种携带道具覆盖自动回复果、异常治疗果、回合回复、物理／特殊增伤、物理减伤、速度、要害及草／火／水增幅。在背包「携带道具」口袋选择伙伴装备，旧道具原样退回背包；伙伴详情可收回。果实仅在触发时消耗，耐用品可重复使用，放生前会收回携带物。背包已满时拒绝会丢失道具的更换或放生。

效果参与实际伤害、速度行动次数、命中、要害与回合结算，双方均适用。道馆与联盟对手会携带果实或护符，战斗属性面板显示双方特性及道具；触发的回复、保命、免疫和消耗会显示在战报。
