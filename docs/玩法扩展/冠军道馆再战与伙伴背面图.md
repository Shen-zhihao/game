# 冠军道馆再战与伙伴背面图

## 冠军后的八馆再战

- 成为联盟冠军、完成对应道馆首通后，与原馆主交谈即可进行强化单打。旧冠军存档不需要重新通关联盟；查看对话不会写入再战记录。
- 八位馆主各使用五只 Lv.58、59、59、60、62 的主题伙伴，分别延续草木、岩石、水、电、飞行、火、超能和星岚队伍特点。使用现有换人、辅助招式与携带物机制，每场最多四次主动换人。
- 每场整队共用两份高浓草露药。低体力用药消耗对手整轮行动，换人不补充，读档不重置余量。
- 每次胜利获得原有馆主档击败经验和金币，以及独立的 3600 金币胜利奖金，仍受金币上限约束。再战次数、胜场单独记录，不写入原馆主获胜事件，不重发徽章、首通关键道具、成长果或高级星纹球，不重置机关。
- 再战可无限重复，不新增日历或联网限制。战败沿用普通对战的 5% 返程费用与治疗中心恢复规则，保留已经结算的击败奖励；回原馆可再挑战，不需重做机关。
- 中途保存保留阵容、行动额度、药量与奖励账本。胜利结果再次读取不会重复发奖；离开结算界面后才能新开一场。联盟再战及规则挑战保持原规则，不能与道馆再战同时进行。
- 内容版本 ch11.3，继续接收 ch11.2 及此前受支持存档。缺少再战记录的旧档按从未再战处理，不在读取时补发奖励。

## 独立背面图

- 三条初始伙伴家族的 001～009 九个形态使用新绘制的后侧三分之四视图，不以正面图翻转代替。
- 我方常规站场、登场、主动换人、强制补位与倒下统一选择背面图。对手、图鉴与队伍菜单继续使用原正面图。
- 其余 241 个形态保留原镜像正面回退。未制作全图鉴背面、攻击逐帧、畏缩或双打。
- 原有正面图集不变。新图集为 1536×1536 透明 PNG，九格隔离，独立裁切元数据与生成来源见美术资源文档。
