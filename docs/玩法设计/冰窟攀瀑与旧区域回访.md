# 冰窟、攀瀑与旧区域回访

## 霜镜冰窟

断风岭保护地东南步道（35,28）向南接入冰窟。亮蓝冰面会沿单一方向持续滑动，撞墙或到达普通地面才停下。斜向摇杆输入归为一个正方向，不能斜穿墙角。滑行逻辑以一个原子指令完成，表现层沿直线播放 85 毫秒／格、最长 1200 毫秒的滑行动画；动画期间忽略新的动作与菜单输入，不在存档里保存半途状态。

从入口（35,36）的一条解法为：左、下、右、下、左、下、右。中间有能够在停点主动选择的错误支路，所有支路都可折返。尽头面向右侧宝箱领取浓缩草露药 ×3、高级星纹球 ×2；向上调查安全返回绳，回到入口外。奖励仅领取一次。

## 镜河攀瀑

九号镜河路（37,20）向东有新增支路，沿路抵达（49,17）的瀑布下方。具备冲浪能力（渡水装备，或灯塔支线后队伍携带冲浪术）和滑翔装备后，向北踏入瀑布便会连续攀升至镜源台地。这是装备配合的野外攀瀑能力，不新增战斗招式或冒领奖章。

向南可以无条件沿安全绳下行，台地另设返回绳。即使更换或失去冲浪伙伴也不会被困。台地藏箱提供成长果 ×1、高级星纹球 ×3，只有一次，不会因离开、读档或再次调查刷新。

## 回访旧区域

森林南侧墙边（24,19）的藤后旧补给箱需要剪藤工具，奖励浓缩草露药 ×2；矿洞南侧墙边（27,23）的岩缝旧补给箱需要碎岩工具，奖励高级星纹球 ×2。两处不改变原主线要求，也不消耗工具。物品达到上限时保留宝箱，不标记已领取。

## 兼容与边界

使用原地图的追加区域和四个独立奖励标记，不增加存档结构字段；旧地图可行走位置不新增 NPC，旧存档无须迁移。所有新标记列入存档校验白名单。既有对战、任务、剧情旗标与遭遇逻辑保持原样。两张扩展地图使用与碰撞网格一致的即时矢量绘制，避免旧静态底图拉伸、错位或隐藏扩展地形。
