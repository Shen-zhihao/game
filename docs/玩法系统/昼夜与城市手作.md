# 昼夜生态与城市手作

适用内容版本：ch11.1。旧版存档无需重开；新增手作记录在首次获得材料时建立。

## 昼夜与休息

- 游戏日历的白天为 06:00–18:00，其他时段为夜晚。
- 普通草丛、水域调查、渡水遭遇、垂钓共用物种与族系的昼夜权重；部分物种仅白天或夜晚出现，图鉴栖息地页显示提示。固定剧情遭遇不受此限制；已经生成的探索发现不因切换时间重新抽取。
- 菜单「城市工坊」可在完成伙伴练习与捕捉教学后，于安全城镇休息至下一个清晨或夜晚。休息只推进日历，不治疗、不推进天气、不增加游玩时长。战斗、对话、待处理成长、活动、规则挑战及联盟挑战期间不能休息。
- 快速旅行不改变时间；设置里的「昼夜光照效果」只控制画面，不改变生态、居民日程或夜市营业。

## 三城生产

从游戏菜单进入「城市工坊」，不需要寻找新增建筑。可以查看三城进度，但制作和交付必须身处对应城镇。

| 城镇   | 原有活动 | 每日材料                 | 配方                   |
| ------ | -------- | ------------------------ | ---------------------- |
| 晨芽镇 | 育苗小园 | 花园麦穗、食用香草，各 3 | 香草小餐包、花园香草饼 |
| 石脊城 | 岩层寻宝 | 平整石料、透光矿晶，各 3 | 矿晶风铃、矿纹路牌     |
| 白帆港 | 白帆垂钓 | 拾得空贝壳、海玻璃，各 3 | 空贝风饰、海玻璃夜灯   |

- 每种来源活动每天首次成功获得材料；失败、打开活动、领取首通奖励不重复发材料。当日重复挑战仍保留原来的步数记录。材料仓满时先制作，再重玩可重新尝试领取。
- 每款配方每次制作消耗两种材料，分别为 2+1 或 1+2。每款成品每日可交付一次订单，获得一枚独立手作印花。
- 白帆港制作与订单仅在夜间开放；垂钓采集全天可做。材料、成品和订单无过期时间，错过夜间可休息后再来。
- 食品只用植物原料；港口制作只用拾得空壳与海玻璃，不消耗精灵。
- 手作库存、印花和收藏独立于战斗背包、旅费与调查印记。原有活动首通奖励不变。
- 每城累计 3 份订单解锁对应纪念章；制作全部六款解锁三城手作图册；累计 18 份订单解锁好邻居纪念章。
- 每种材料或成品上限 999；制作、采集和订单累计记录上限 999999。达到上限时不扣除材料或成品。

## 居民日程

三城各增加一位闲聊居民，按已保存的昼夜时间切换位置与对白。原有剧情人物、服务人员、任务入口不会移动或消失；新位置会避让玩家、门口、已有角色与巡逻线路。

## 存档

材料、制作、订单与收藏使用独立守恒校验，并限制已领取日期不超过游戏日历。读取、快速旅行、菜单切换和当日重玩不会额外发放材料或印花。旧存档缺少手作字段时按未开始处理。
