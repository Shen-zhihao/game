# 条件捕捉球

四种球均在完成捕捉入门后，于已开放城镇的补给商店购买。它们属于精灵球口袋，可在普通野生或已开放的剧情野生遭遇使用，不可捕捉训练师伙伴或救援序章精灵。

| ---------- | ---: | -------------------------------------------------- |
| 先机星纹球 |  700 | 第 1 回合 ×4，之后 ×1                              |
| 计时星纹球 |  600 | ×min(4, 1 + 0.3 ×已完成回合数)，第 11 回合达到上限 |
| 夜幕星纹球 |  650 | 游戏时间 18:00 至次日 06:00 前 ×3，白天 ×1         |
| 水网星纹球 |  650 | 目标包含水属性时 ×3，否则 ×1                       |

## 条件口径

- 一回合内可以有多次行动。先机球在第 1 回合的每次投球均适用；计时球只统计已完成的整回合，不因多次行动重复增加倍率。
- 夜幕球读取存档中的游戏日历，不读取设备时间，也不受昼夜显示或亮度偏好影响。没有日历字段的旧存档沿用根据游玩时间推算日历的既有兼容逻辑。
- 水网球只看目标精灵的属性。水边、水面、钓鱼、降雨均不会单独触发加成；双属性中含水属性即可。
- 战斗背包同时显示当前倍率、生效原因和最终概率。预览与实际投球共用同一条件计算函数。

## 概率与消耗

条件倍率接入既有捕获公式，与种族捕获率、种族强度及等级修正、剩余 HP 和异常状态共同计算，最终概率限制在 3% 至 95%。这些球不是必定捕获；只有原有大师球或捕捉教学的保证成功规则保持不变。

每次有效投球消耗一个球和一次行动，失败后继续既有战斗流程。打开、切换或关闭背包预览不扣球、不推进回合。库存不足、训练师战斗或队伍与仓库均满时禁止投球，不消耗道具。

## 存档兼容

不新增必填存档字段。旧存档没有这些球的库存时视为零，可照常购买；原有球种及缺少摇晃次数的旧捕获动画记录仍受支持。新球种加入捕获动画存档校验，保存后可正常读取。
