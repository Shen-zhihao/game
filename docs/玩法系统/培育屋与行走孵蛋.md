# 培育屋与行走孵蛋

## 入口和规则

完成捕捉入门后，在晨芽镇或其室内打开菜单「培育屋」。岚博士会介绍服务。其他地点可以查看进度；寄存、接回、领取蛋需要回晨芽镇，孵化可在安全场景确认。

本作采用简化的同家族培育规则，不模拟原作特定世代的性别、蛋组或个体值遗传。两位不同个体、同一普通家族、等级达到 10 的伙伴才可配对；剧情稀有家族（含初始伙伴家族）不参与。后代是该家族的初始形态，等级 1。

## 完整循环

1. 寄存两位符合条件的伙伴。寄存伙伴保留在仓库并被锁定，仍占仓库位置；队伍伙伴寄存时移入仓库。不能寄存最后一位可战斗伙伴。
2. 正常探索累计 64 次成功移动，培育屋准备好一枚蛋。原地等待、撞墙、对话或战斗不会增加步数。
3. 回晨芽镇领取，蛋放在独立的携带栏，不占队伍格，不会参加战斗。
4. 携蛋成功移动 128 次后，在「培育屋」页面确认孵化。新伙伴优先进入队伍，其次进入仓库；两处全满则保留蛋与完成进度，整理后再孵化。
5. 随时回晨芽镇接回亲代。接回解除仓库锁定，不强制挤入队伍；未完成的配对步数重置，已有蛋保留。

同时最多保有一枚待领取或携带中的蛋。有蛋时不继续准备另一枚。孵化结束后，若两位亲代仍寄存，可开始下一轮。

## 少量招式遗传

只考虑两位亲代当前共同掌握、且属于后代初始形态学习表的合规招式。最多继承两个，去重；排除专属招式、挣扎和剧情通用技能，不绕过探索剧情门槛。继承招式以完整 PP 出生并记录在技能册，遗忘后可按既有回忆规则重学。其他出生招式按通常规则补足，最多四个。

亲代的等级、能力、道具、亲密度、技能及历史不会因培育改写。后代采用正常的新伙伴成长机制，不引入 IV／性格重做或闪光系统。

## 存档与边界

旧存档不含培育记录时按空培育屋处理，无须另开存档。存档校验检查寄存引用、重复亲代、蛋的种族与合法招式、步数范围和单蛋限制；异常记录不会静默吞掉亲代或生成重复蛋。

保育园原有赠送两种初始伙伴的剧情保持独立；培育屋不替代、重复发放或改写该奖励。

## 本次验证

通过 TypeScript 与 ESLint；验证旧存档、异常引用、非法遗传、容量上限、最后可战斗伙伴、重复操作、战斗和成长选择期间的门槛。云浏览器实测寄养、64 步产蛋、领蛋、128 步后主动孵化、亲代取回，以及中途保存并重载；导出的实际浏览器存档确认仅新增一位 Lv.1 后代，双亲记录未改写，两项遗传招式保留。原有捕捉、冰面／攀瀑、战术对战、亲密进化、道馆重战回归检查通过。未执行安装包构建、原生真机验证或部署。
