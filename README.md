# 绮梦物语

《绮梦物语》是捕捉、培养、进化并挑战道馆的原创精灵 RPG，使用 React Native / Expo 开发。横屏精细像素探索、回合制战斗、捕捉、成长进化、本地存档与同一 Wi-Fi 双机传档。Android 仅 `arm64-v8a`，同时实现 iOS 客户端。

当前内容版本为 `ch10.4`，App `0.1.0 (1)`：46 张地图、八座自由顺序道馆、完整地区危机、四位精英与六只队伍冠军、24 条居民故事、通关后保育研究。250 种形态均有独立正面图与实际获取／进化路径，可在同一存档收集。

## 运行

```sh
pnpm install --frozen-lockfile
pnpm web
```

打开 `http://localhost:8088`。方向键 / WASD 移动（同时按两个方向可斜走），Enter / Z 或 A 交谈，Esc / X 逐层返回。手机使用半透明万向摇杆和 A 按钮，拖动摇杆八向移动，松手停止；可在“设置 → 按钮布局”调整位置、大小和摇杆透明度，横竖屏分别保存。菜单查看队伍、仓库、精灵中心、背包、图鉴、任务、全地区地图和存档。

```sh
pnpm android
pnpm ios
```

原生依赖包括 TCP、Bonjour、SQLite、扫码相机与系统触感，Expo Go 不包含完整功能。首次生成原生工程可使用 `pnpm exec expo prebuild --platform android` 或 `--platform ios`；该命令会重新生成工程，配置源是 `app.config.ts`。iOS 最低 16.4，Android compile / target SDK 36。

## 完整旅程

- 先搬家、结识阿澈，在草丛调查博士背包，借用伙伴救人，再正式获赠同一只精灵。回研究所领取图鉴与补给，完成捕捉入门。
- 八座道馆为苔丘、石脊、潮汐、雷鸣、风栖、炉心、镜湖、星岚。只要求入门和本馆机关／练习，不要求其他徽章、地区调查或稀有捕获；强度按已有徽章调整。
- 地区调查沿森林晶丝、矿山箱号、港口运单、电站旁路、风道回流、熔炉校准件、镜湖公开档案，到星核三路复原完整收束。解决危机靠恢复设备与回流，不强制捕获传说精灵。
- 八枚不同徽章解锁联盟资格；完成阿澈的终场切磋后，连续挑战冰、幽灵、恶、龙四位精英与冠军。中途保存可继续，离场／战败重开本轮，已获得经验与金币保留。首次与最近冠军队伍独立写入名录。
- 联盟和地区主线可按任意顺序完成，两者结案后出现完整归途对白。全部支线可通关后补做，没有现实时间、联网、随机掉落或必抓稀有精灵的主线门槛。
- 通关后回晨芽镇，博士观察册、四生境研究与保育园赠予另外两种初始伙伴的新个体。旧铃、山道、深矿、海藻湾、九城合照、双衡古庙和终宵厅各有完整记录。249 双衡星兽与 250 终宵烛龙有独立前置，击倒／逃跑／战败都能重试，捕获后不重复生成。

## 培养与战斗

- 入场陷阱：岩石伙伴 Lv.20 可学隐形岩，地面／虫伙伴 Lv.20 可学撒地刺；所有伙伴 Lv.18 可学清扫场地，已有伙伴可通过技能回忆补学。隐形岩在换入时造成最大HP的1/8乘岩石相性伤害；地刺最多三层，接地伙伴换入分别扣1/8、1/6、1/4最大HP，飞行及轻浮免疫地刺。清扫仅清除己方陷阱；守住不阻挡场地布置。陷阱跟随双方场地而非个体，支持替补上场、连环入场倒下及中途存读档；新战斗清空。

- 满级100，每次升级随机获得1–10能力点，家族强度越高越容易获得高点数（三档平均4／5.5／7点）；支持手动、推荐预览与自动培养。250 份专属方案说明能力权重、配招、弱点和进化。确认后只能在背包使用重塑药剂返还已分配点数，伙伴页只允许分配剩余点数。升级达到自然学招等级时自动学习，满四招时选择替换。新精灵不生成个体值、性格或努力值。
- 18 属性标准克制表，支持多个不同属性叠乘。250种实际组合均有弱点和抗性，各附加属性都有防御或攻击覆盖收益，实际投放的弱点最高4倍。普通190种为148种单属性、42种双属性；稀有49种中有12种单系专精，其余按具体能力配置多属性；双衡星兽纯超能力，终宵烛龙为龙／幽灵／火／冰。速度决定先手；达到对手 2 倍／3 倍速度时技能最多连续 2／3 次，逐次扣 PP，用药、换人、投球不连用。命中、闪避、要害与抗要害可由技能调整，要害伤害为 2 倍。
- 战斗过程自动播放，默认每条2秒，设置可选0.5／1／2／3／5秒；完整播放技能动画后自动推进，结果展示后自动返回。技能、道具、换人和后续操作仍由玩家选择；可暂停或快进，查看战报和进入后台暂停。开局两套旅行者外观即时预览，地图与读档使用原来选择的行装。
- 全部111招均有动作或画面特效：18属性攻击、治疗、强化、削弱和天气；每次实际出手分别演出，未命中／免疫没有虚假受击，动画中防止重复输入，读档不重播旧回合。九种地区主题战场明确覆盖46张地图；六种新增场景为雷鸣、风栖、炉心、镜湖、星岚和联盟，精英战按属性切换。
- 回复药先选对象再确认，取消或无效使用不消耗；主动换人占一回合，倒下补位免费。每击败一只即时获得经验与金币，NPC 高于野外，馆主更高；新徽章另有阶梯奖励，读档不重复入账。
- 战败后按实际道路距离，返回已经到达过的城市中最近的精灵中心室内，恢复全队 HP／PP／异常。进入城市即解锁复活地点，无需先治疗；城市记录随存档共享。联盟战败也在附近中心恢复并重置本轮连战。
- 各城精灵中心免费恢复全队 HP／PP／异常，并可遗忘和重学。剪藤、碎岩、冲浪先解锁对应故事，随后可教任意伙伴。技能复刻剂可复制伙伴当前普通技能给任意自有精灵，来源保留原技能；51种稀有／神兽形态各有一招专属技能，其他形态不能学习，复刻剂不能复制。稀有形态Lv.15、神兽Lv.50解锁，进化时已学专属招式转换为新形态对应技能并保留剩余PP。
- 7 种天气影响野外概率、移动与战斗；不同地形改变步速。工具只增加可选捷径，普通道路始终可走。稀有与强力精灵更难捕获，普通随机池排除剧情家族。
- 大师球全篇正常最多三枚：潮闸结案、古庙约定、联盟生态研究；每处一次，不出售、不兑换、不随机掉落。账本随存档传输。
- 背包按精灵球、回复、培养、进化、重要物品分袋。
- 十座城镇／联盟采用不同地面：花园砖、苔缝石、玄武岩、木栈道、铜缝板、霜边岩、火山砖、青银石、星纹街砖与金线礼仪石坪。自然天气按草原、森林、海滨、高地、高山、火山、湖畔、台地气候轮换，炉心不自然降雪。
- 按钮、菜单、摇杆与战斗命中提供触感反馈；设置可统一关闭并保存在本机，长按移动不逐格震动。Android和iOS接入系统触感，网页只在浏览器支持时响应。新增原生模块需要重建客户端；本轮未打包和验收物理马达。
- 队伍 6 只，仓库 360 位。城镇可确认放生仓库个体以腾出容量，图鉴、剧情和冠军名录保留。精灵使用独立正面形象与待机动画，按完整透明轮廓取图并留出边距，避免火焰、尾巴被方格截断和相邻精灵串图；神兽图集及萤羽蛾已重绘。我方战斗使用翻转图，完整独立背面和逐帧攻击图尚未制作，技能画面与动作由RN／SVG实现。

## 多段攻击与反冲

「双重击」每段35威力、固定两击；「藤鞭连击」每段20威力，按35%／35%／15%／15%概率连续2／3／4／5击。整招只扣一次PP、判定一次命中；每段独立判定要害与伤害，并处理岩心、吸取和树果，任一方倒下即停止，不攻击下一只。每段有独立画面与日志，与速度优势带来的每轮多次行动不同。

所有伙伴Lv.16可学双重击、Lv.24可学「舍身冲撞」（90威力，按实际造成伤害的1/3反冲，向下取整且至少1点）；旧伙伴可技能回忆。过量伤害不计入反冲，未命中、免疫、守住时无反冲；奋力一搏仍单独按自身最大HP的1/4反冲。反冲双方同时倒下沿用既有胜负规则：我方无可战斗伙伴时判负。

## 冠军挑战

成为冠军后，在安全城镇的「菜单 → 规则挑战」可参加自有队伍单打或租借队伍挑战。租借模式先从六只 Lv.50 候选中选择三只，连续获胜三场即通关；前两场获胜后可从刚击败的队伍中换入一只，也可直接继续。每场恢复租借队伍的体力、技能次数和携带道具，禁止使用背包、捕捉或普通逃跑；战斗指令中的「退出租借」可结束本轮。

租借挑战新开场次按固定三关递进：岑岩的攻防基础、泠川的陷阱与接力、岚衡大师的均衡破阵。双方仍统一 Lv.50，难度来自合法配招、携带物和队伍协作，不额外抬高等级或能力。登记与换人前可查看下一关主题提示；已保存的旧战斗保留原对手，不会在读档时重抽。

候选、参赛与换入伙伴都有独立的展开详情按钮，查看不会选中或换人；详情按下一场实际统一培养展示能力、特性、携带物和完整招式效果。队伍弱点表统计属性相性与特性免疫，不预测天气、道具、剩余HP或条件减伤后的实际生存能力。

候选选择、战中进度及胜后换人状态均随存档保留。自己的精灵、队伍与仓库顺序、物品和图鉴不被租借玩法改写，满队伍及满仓库也能参加。通关、败北或主动退出时归还租借伙伴并恢复原队伍；奖励只有挑战积分与租借通关纪录，没有经验、金币或图鉴登记。原有自有队伍单打与积分兑换保留。

## 本地存档与双机传档

默认显示至少3个槽位，可持续新增独立存档，填满后自动提供下一个空槽。打开「本地存档 → 另存为新档并继续」可保留旧检查点，后续自动保存只写入新槽。任意选择槽位后读取；切换玩家前保存离开的进度，重读当前槽不先覆盖已有存档。每槽保留10份历史，覆盖导入前另留保护备份。网页使用 localStorage，手机使用 SQLite；旧三槽数据原样保留，读取支持 `ch1.1` 起所有已发布内容版本，安全操作只补建新增地图，不重置原有发现、伙伴或剧情。

标题页可直接进入「读取存档 / 管理」。先选择一个槽位，再按「读取所选存档」；每次只加载这一份。分享文件和历史恢复也逐份操作。导入单档可新增并直接读取；旧合集仍兼容，但先从中选一份，随后只导入和读取所选条目，不再提供全部分享或全部导入操作。文件包含完整角色、伙伴、道具、剧情、随机状态与战斗／成长检查点，不绑定账号、设备或原槽位。单档上限8 MiB，旧合集上限64 MiB；本机原档保留，显式覆盖所选槽仍需再次确认并留保护备份。

两部手机连接同一 Wi-Fi，接收端打开「存档互传 → 接收」，发送端搜索设备并扫描配对码，接收端预览后选择槽位确认，默认选空槽。二维码绑定临时公钥与会话凭据，NaCl box 加密分块，接收端校验 SHA-256／版本／业务规则后原子提交并回执。文件分享不要求两位玩家处在同一 Wi-Fi，也不依赖后台服务；访客网络隔离仍会阻止设备直连。

此前的 Node TCP 验证覆盖完整剧情、冠军队伍、初始保育与限量球账本。物理 Android ↔ iPhone 的发现、扫码、权限与双向 Wi-Fi 矩阵仍需真机验收；loopback、模拟器或静态检查不代表该矩阵已通过。

## 检查、图鉴与构建

```sh
pnpm check
pnpm format:check
pnpm exec expo install --check
git diff --check
pnpm exec tsx tools/export-battle-skills.ts
pnpm exec tsx tools/export-dex.ts
pnpm exec tsx tools/export-type-balance.ts
```

`pnpm check` 执行类型检查和 ESLint。项目不维护 `tests` 目录及专用测试脚本；每次改动所需的功能验证由 Codex 自行处理，临时验证脚本保存在仓库外。具体约定见 `AGENTS.md`。

`tools/export-dex.ts` 生成完整 250 种图鉴数据与离线可检索 HTML，含图片、属性、栖地、剧情获取、进化、学招与培养方案。文件在 `docs/图鉴/图鉴数据.json` 和 `exports/stargrove-dex.html`。

`assets` 只保留当前使用的图片；已删除旧地图的生成提示和替代关系保存在美术清单的 `retiredAssets`，无需保留旧位图。安装 `oxipng` 和 Pillow 后，可运行 `python3 tools/optimize-assets.py` 预览无损压缩，添加 `--apply` 才替换；可加 `--level 6` 提高无损搜索等级：全部图片先通过尺寸、完整 RGBA 像素及颜色元数据核对，再仅替换变小的文件。压缩不改变分辨率或透明像素中的颜色值。历次清理与压缩记录见 `docs/美术资源/资源优化记录.json`。

新图片应先优化再首次提交。给已提交图片追加删除或压缩提交，不会清除旧提交中的原图。2026-10-16 将远端之后的11个本地提交及当前代码、资源清理改动合并为一个本地提交，新增历史只保留最终压缩资源；远端已有历史保持原样。原章节提交编号和旧包来源仍属于整理前的验证记录，可从仓库外备份追溯。

章节开发期间只做常规测试和逐章提交，全部剧情完成后才统一进行 Web／Android／iOS 导出、原生 Release 构建与启动测试。最新产物、签名用途、源码指纹与 SHA-256 记录在 `exports/artifacts.json`；iOS 模拟器 ZIP 不能安装到 iPhone，设备目标仍需开发者签名后安装。

每次打包在新包验证成功、更新 `exports/artifacts.json` 后，执行 `pnpm package:finalize`：核对交付文件体积与 SHA-256，清除旧同类包、旧支持文件、临时脚本／日志及 iOS／Metro 导出缓存，保留各平台最新包、当前包支持资料、验收图片和存档，并统一更新 `SHA256SUMS.txt`。`supportFiles` 数组指定当前包仍需保留的构建日志、签名检查和 mapping 等文件；`pnpm exports:clean` 可预览清理清单。构建失败时保留旧包；其他平台／环境的包和 Xcode Archives 保留。完整收尾要求见 `AGENTS.md`。
